Base de Datos en la Nube (Supabase)

Conecta tu proyecto de Supabase (PostgreSQL + Auth + Storage) para sincronizar los moldes, las ventas y las fotos en tiempo real desde cualquier dispositivo.

Modo Local Activo (localStorage)
Encuéntrala en: Supabase Dashboard → Tu Proyecto → Settings → API → Project URL
Encuéntrala en: Settings → API → Project API Keys → anon / public
Pasos para conectar:
  1. Crea un proyecto gratis en supabase.com.
  2. En el SQL Editor de Supabase ejecuta el script supabase-schema.sql.
  3. Pega tu URL y anon key aquí arriba y haz clic en Guardar y Conectar.
